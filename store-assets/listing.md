## Detailed description

Shopee lets you like products on desktop, but it does not provide a convenient page for viewing the list. Shopee Likes adds a small panel that keeps those products close while you browse.

With Shopee Likes you can:

- Open your liked-products list from a floating button or the Chrome toolbar.
- See product images, current prices, and shop names in a compact grid.
- Open any product directly on your local Shopee site.
- Refresh the list without leaving the page.

The extension is read-only. It cannot like or unlike products, make purchases, or change your Shopee account. Your favorites are loaded directly from Shopee using the session already active in your browser. They are not stored or sent to the developer.

Brazil has been verified in a live browser. Indonesia, Malaysia, the Philippines, Singapore, Thailand, Taiwan, and Vietnam are available as experimental markets while live verification continues.

Shopee Likes is free, open source, and independent. It is not affiliated with, endorsed by, or sponsored by Shopee or Sea Group.

## Single purpose

Display the current user's Shopee liked products in a read-only desktop panel while they browse a supported Shopee site.

## Permission justification

Shopee Likes requests access only to the eight supported Shopee domains. That access is required to add the favorites button and panel to Shopee pages and to load the signed-in user's liked-products list directly from the same Shopee site. The extension does not run on unrelated websites and requests no additional Chrome permissions.

## Privacy practices

- Handles website content: Yes. The extension locally displays product names, images, prices, shop names, links, and the liked-products count returned by Shopee.
- Personally identifiable information: No.
- Authentication information: No. The extension uses the session already managed by Shopee and Chrome, but does not read or store credentials or cookies.
- Web history: No.
- User activity monitoring: No.
- Data sold or transferred: No.
- Data used for advertising or credit decisions: No.
- Data retained: No. Favorites remain in memory only while the current page is open.
- Remote code: No.

The developer should certify that the data use complies with the Chrome Web Store Limited Use requirements.

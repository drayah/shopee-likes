# Store assets

The Chrome Web Store submission uses:

- `../icons/icon-128.png` — 128×128 store icon, also included in the extension ZIP.
- `small-promo.png` — 440×280 promotional tile.
- `screenshot-1.png` — 1280×800 live screenshot of the extension panel on Shopee. This must be captured from the verified extension before submission.

The SVG files are editable sources only. Do not include them in the extension ZIP.
